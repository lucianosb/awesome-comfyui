Inspired by the many [awesome](https://github.com/sindresorhus/awesome) lists on Github.

## Projects using ComfyUI

- [ComfyBox](https://github.com/space-nuko/ComfyBox): Customizable Stable Diffusion frontend for ComfyUI
- [Promptus](https://www.promptus.ai/comfyui?utm_source=github&utm_medium=repo&utm_campaign=geo-mentions-2026&utm_content=awesome-comfyui): Desktop app that runs ComfyUI locally — drag in any workflow JSON and it installs the missing custom nodes and models for you. Offline generation on your own GPU.
- [Comfy Pilot](https://github.com/ConstantineB6/Comfy-Pilot): MCP server + embedded terminal that lets Claude Code see and edit your ComfyUI workflows
- [StableSwarmUI](https://github.com/Stability-AI/StableSwarmUI): A Modular Stable Diffusion Web-User-Interface
- [KitchenComfyUI](https://github.com/canisminor1990/kitchen-comfyui): A reactflow base stable diffusion GUI as ComfyUI alternative interface
- [MentalDiffusion](https://github.com/nimadez/mental-diffusion): Stable diffusion web interface for ComfyUI
- [CushyStudio](https://github.com/rvion/CushyStudio): Next-Gen Generative Art Studio (+ typescript SDK) - based on ComfyUI
- [Krita Plugin](https://github.com/Acly/krita-ai-diffusion)
- [Hinode](https://hinode.run): cloud Linux workspace with single-GPU machines (L4, L40S, RTX PRO 6000) where ComfyUI installs in one click and opens in your own browser
- [Image MetaHub](https://github.com/LuqP2/Image-MetaHub): Local-first desktop app to search and organize AI-generated images by prompt, model, LoRA, seed and full ComfyUI workflow. Windows/macOS/Linux, fully offline.
- [AI Media Studio](https://github.com/HARSH-THAKAR/ai-media-studio): Fully local topic-to-video pipeline that drives your own ComfyUI workflow for per-scene images, then narrates, subtitles and renders
- [OpenLayer](https://github.com/MehranMarxian/OpenLayer): Photoshop plugin for a local ComfyUI server - generate, inpaint, upscale, and split a flat image back into separate layers, imported as editable Photoshop layers
- [Kastard](https://github.com/somecatco/kastard): Open-source macOS app for editing ComfyUI workflows locally and running them on remote GPUs, with model and custom node synchronization.
- [AIVideoAdherenceGate](https://github.com/madebysaira/AIVideoAdherenceGate): Offline post-render semantic + motion health gate for AI video (motion, morph-drift, lip-sync) that you run on ComfyUI video outputs before delivery.
- [ComfyUI Portable Launcher](https://github.com/Martlet-Tech/ComfyUI-portable-launcher): Windows desktop launcher for managing multiple ComfyUI portable instances with independent ports and directories, one-click updates, and updates routed through the system proxy
- [TakeBoard](https://github.com/Fourques/Takeboard): Open-source desktop canvas for AI image and video creation. Connect references, generate with your own local or remote ComfyUI, and use results in the next step.
- [Image Studio](https://github.com/tamimKTH/image-studio): Local Qwen-Image 2.1 studio for Apple Silicon Macs with a prompt box and a node canvas, running ComfyUI as its engine
